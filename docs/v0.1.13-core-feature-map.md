# GoDesk v0.1.13 核心功能清单与原界面映射表

> 基线版本：v0.1.12 封版源码。本文只描述现有功能、保全位置和验收方式；v0.1.12 Release 不改动。v0.1.13 的新界面必须以本表逐项验收。

## 1. 信息架构原则

| 新界面区域 | 原实现入口 | 保全要求 | 验收方式 |
|---|---|---|---|
| 连接工作区 | `App/Client/mainwindow.cpp`、`Recent/FrmRecent.cpp`、`Favorite/FavoriteView.cpp` | 新建、打开、编辑、收藏、最近、活动、搜索、分组和批量操作都由原对象/信号驱动 | 每个入口能打开原设置/连接对象并完成保存、连接、关闭 |
| 五大分类 | `Src/Plugin.h` 的 `CPlugin::TYPE`、`MainWindow::UpdateMenuStart()` | 远程桌面、终端、服务、网络工具、工具均由已加载插件动态生成 | 插件实际加载后，分类下出现真实协议入口；新建后能连接或打开原工作区 |
| 会话区 | `View`、`ViewTable`、`ViewSplitter`、`FrmFullScreenToolBar` | 标签页、分屏、全屏、停止、重连、关闭、工具栏和会话菜单继续使用原信号槽 | 至少建立一个连接后逐项操作并验证视图状态 |
| 设置中心 | `MainWindow::on_actionSettings_triggered()`、`CParameterDlgSettings::AddViewers()`、各 `CParameterUI` | 通用、主窗口、插件、数据库、终端、录制、多媒体、更新、日志等页面不得删减 | 设置页逐页打开；修改后重启并确认值持久化 |
| 数据与安装 | `Package/NSIS/Windows.nsi`、`RabbitCommon::CDir`、新 `GoDeskDataPaths` | 安装目录、data、config、plugins、logs、cache、update 显示绝对路径并可迁移 | D/E/F 盘安装、无写权限回退、升级迁移、路径展示和打开目录测试 |

## 2. 五大分类与全部插件入口

| 分类 | 源码/插件 | 二级协议或功能 | 新界面位置 | 验收 |
|---|---|---|---|---|
| 远程桌面 | `Plugins/FreeRDP/Client` | FreeRDP/RDP：服务器、用户认证、代理、显示、音频、剪贴板、本地资源、驱动器 | 远程桌面 → RDP | 打开设置，保存 `.rrc`，连接并验证会话菜单 |
| 远程桌面 | `Plugins/RabbitVNC/Client` | RabbitVNC：地址、认证、显示与会话 | 远程桌面 → RabbitVNC | 新建并打开原 VNC 会话 |
| 远程桌面 | `Plugins/LibVNCServer/Client` | LibVNC：VNC 连接、认证、代理/隧道 | 远程桌面 → LibVNC | 新建、连接、停止 |
| 远程桌面 | `Plugins/TigerVnc/Client` | TigerVNC：VNC/X509 认证、代理/SSH 隧道、显示 | 远程桌面 → TigerVNC | 打开原设置并连接 |
| 远程桌面 | `Plugins/Template/Desktop` | 桌面插件模板入口（若构建启用） | 远程桌面 → 模板 | 插件加载后显示真实入口；未构建时明确标注不可用 |
| 终端 | `Plugins/SSH` | SSH 终端、密码/公钥认证、命令/隧道 | 终端 → SSH | 新建、保存、连接、断开 |
| 终端 | `Plugins/Telnet` | Telnet、用户密码、命令列表 | 终端 → Telnet | 新建、连接、停止 |
| 终端 | `Plugins/SerialPort` | 串口终端、串口参数 | 终端 → 串口 | 打开设置并验证设备枚举 |
| 终端 | `Plugins/RawStream` | TCP 原始流/命名管道（构建可用项） | 终端 → Raw Stream | 新建并验证 TCP 参数 |
| 终端 | `Plugins/Terminal` | 通用终端参数、字体、颜色、滚动、快捷键 | 终端 → 通用终端 | 设置持久化 |
| 服务 | `Plugins/FreeRDP/Server` | FreeRDP 服务 | 服务 → FreeRDP | 创建服务配置并由 ServiceManager 加载 |
| 服务 | `Plugins/FtpServer` | FTP 服务 | 服务 → FTP | 服务配置页可打开、保存 |
| 服务 | `Plugins/SftpServer` | SFTP 服务 | 服务 → SFTP | 服务配置页可打开、保存 |
| 服务 | `Plugins/LibVNCServer/Service` | LibVNC 服务 | 服务 → LibVNC | 服务加载/停止 |
| 服务 | `Plugins/RabbitVNC/Service` | RabbitVNC 服务 | 服务 → RabbitVNC | 服务加载/停止 |
| 服务 | `Plugins/TigerVnc/Service` | TigerVNC 服务 | 服务 → TigerVNC | 服务加载/停止 |
| 服务 | `Plugins/Template/Server` | 服务插件模板（若构建启用） | 服务 → 模板 | 真实插件状态验收 |
| 网络工具 | `Plugins/WakeOnLan` | Wake-on-LAN、网卡/目标地址 | 网络工具 → Wake-on-LAN | 选择网卡并发送唤醒 |
| 网络工具 | `Plugins/FileTransfer` | 文件传输、远程目录/文件、新建目录、上传、下载、删除、重命名 | 网络工具 → 文件传输 | 建立 SFTP/远端会话并验证文件操作 |
| 工具 | `Plugins/WebBrowser` | 浏览器、书签、历史、下载、扩展、凭据 | 工具 → 浏览器 | 打开页面、书签/历史读写 |
| 工具 | `Plugins/Player` | 摄像头/URL 播放、多媒体设备 | 工具 → 播放器 | 摄像头和 URL 两种模式 |
| 工具 | `Plugins/ScreenCapture` | 屏幕截图/录制入口 | 工具 → 屏幕捕获 | 截图/录制路径正确 |
| 工具 | `Plugins/Template/Base`、`QtEvent`、`Desktop` | 模板插件（构建启用时） | 工具 → 模板 | 不隐藏真实加载状态 |

插件真实注册链路：`CManager::LoadPlugins()` → `CManager::AppendPlugin()` → `MainWindow::UpdateMenuStart()` / `UpdatePluginMenu()`。新界面不能复制一份静态名称列表替代这条链路。

## 3. 连接管理与会话操作

| 能力 | 原源码入口 | 新界面位置 | 验收 |
|---|---|---|---|
| 新建协议连接 | `CManager::CreateOperate()`、`CPlugin::CreateOperate()`、`MainWindow::GetStartAction()` | “新建连接”及五大分类二级入口 | 所有已加载插件都能弹出原参数页 |
| 编辑/保存 | `slotOpenFile(..., true)`、`COperate::Save()`、`CParameter::Save()` | 连接卡片/会话菜单“编辑” | 修改后保存并重启复现 |
| 复制/克隆 | `MainWindow::on_actionClone_triggered()` | 当前连接更多操作 | 克隆对象 ID 不冲突且参数独立 |
| 删除 | `CManageBackend::slotDeleteBackend()`、插件 `DeleteOperate()` | 卡片/列表批量操作 | 删除后列表、收藏、最近状态一致 |
| 收藏 | `Favorite/FavoriteView`、`on_actionAdd_to_favorite_triggered()` | 收藏导航/卡片操作 | 收藏、取消收藏、启动 |
| 最近连接 | `Recent/FrmRecent`、`RecentDatabase` | 最近导航 | 导入/导出和打开保持原行为 |
| 活动列表 | `FrmActive`、`menuActivity`、`slotUpdateActivityMenu()` | 活动导航 | 连接中对象可切换、停止、停止全部/其他 |
| 打开/导入 `.rrc` | `on_actionOpenRRCFile_triggered()`、`CManager::LoadOperate()` | 导入连接文件 | 外部 `.rrc` 可打开并显示协议 |
| 搜索/分组/批量 | `ViewTable`、`FavoriteView`、`RecentView` 现有模型 | 连接工作区工具栏 | 先复用现有模型和选择状态；缺失时需在映射表中标注实现项 |
| 标签/分屏/全屏 | `ViewTable`、`ViewSplitter`、`FrmFullScreenToolBar`、`on_actionView*` | 会话区顶部 | Tab/Split/全屏切换、关闭恢复 |
| 停止/重连/关闭 | `on_actionStop*`、`COperate::Stop/Start`、`slotCloseView` | 当前会话操作 | 连接状态与活动列表同步 |

## 5. v0.1.13 路径基线

| 类型 | 默认策略 | 回退/兼容策略 | 代码边界 |
|---|---|---|---|
| 程序 | NSIS `$INSTDIR`，默认 `%LOCALAPPDATA%\GoDesk`；读取上次安装目录 | 目录页选择必须生效；升级使用注册表保存的安装目录 | `Package/NSIS/Windows.nsi` |
| 持久数据根 | `<安装目录>\data` | 不可写时 `%LOCALAPPDATA%\GoDesk\data`；兼容旧版 `Documents\Rabbit\GoDesk` | 启动早期初始化后调用 `CDir::SetDirUserDocument()` |
| 配置 | `<data>\etc` 与 `<data>\GoDesk.conf` | 随数据根迁移；保留旧目录备份 | `CDir::GetDirUserConfig/GetFileUserConfigure` |
| 数据/连接/数据库 | `<data>\share`、`<data>\share\db` | 迁移旧 `share`；不删除源目录直到验证完成 | `CDir::GetDirUserData/GetDirUserDatabase` |
| 插件 | 内置插件 `<安装目录>\plugins`；用户插件 `<data>\plugins` | 插件设置页可配置多个真实目录 | `CDir::GetDirPlugins`、`CParameterPlugin`、`CManager` |
| 日志 | `<data>\log` | 不可写时 `%TEMP%\log\Rabbit\GoDesk` | 需要统一 RabbitCommon 日志路径或提供 GoDesk 日志目录映射 |
| 缓存 | `<data>\cache` | `%LOCALAPPDATA%\GoDesk\cache` | WebEngine/临时缓存逐项迁移 |
| 更新下载 | `%TEMP%\GoDesk\<asset>` | 失败时提示并保留路径 | `GoDeskUpdateDialog` |

## 6. 版本验收门槛

1. 先完成本表和路径盘点；提交中不得修改 v0.1.12 Release。
2. v0.1.13 Windows 安装器：选择 D/E/F 盘后注册表、快捷方式、程序启动路径全部落在所选盘。
3. 已存在旧版数据时升级后连接、收藏、最近、插件设置、数据库和窗口设置均可读；旧目录保留可回滚。
4. 安装目录不可写时自动回退，并在设置页显示实际绝对路径；只有 C 盘时仍能启动。
5. 新界面按本表逐项打开真实入口；任何缺失功能必须在提交说明中列出原因，不得静默移除。
